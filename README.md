# 🚀 My Personal Portfolio Website

Welcome to my personal portfolio website repository! This project was built step-by-step throughout my **Web Development & Programming Internship** (Modules 01 to 06), showcasing my skills, projects, resume, and contact details.

## 📚 Internship Modules & Progress

- **Module 1: Basic Structure**  
  Set up the initial HTML5 structure using semantic tags and created the foundational layout for the portfolio website.
- **Module 2: Styling & Assets**  
  Added CSS3 styling, organized asset folders, and integrated profile and background images.
- **Module 3: Dark/Light Mode**  
  Implemented a dynamic theme toggle using JavaScript with `localStorage` persistence across page reloads.
- **Module 4: Projects, Education & Resume**  
  Designed interactive project showcase cards linking to previous GitHub repositories, along with an Education & Resume section featuring a downloadable resume.
- **Module 5: Contact & Website Deployment**  
  Built an interactive Contact Me form with social links (Email, LinkedIn, GitHub), deployed the website live using GitHub Pages, and tested responsiveness across mobile and desktop devices.
- **Module 6: Final Portfolio Submission**  
  Reviewed the entire portfolio, fixed design and layout issues, improved overall performance and responsiveness, and added this professional `README.md` documentation.

## 📌 Key Features
- **Responsive Design:** Fully adaptable across mobile phones, tablets, and desktop screens.
- **Dark/Light Mode:** Smooth theme switching that remembers user preference.
- **Project Showcase:** Highlights completed internship modules with direct GitHub links.
- **Downloadable Resume:** Built-in resume download button.
- **Interactive Contact Section:** Clean form layout for Email, LinkedIn, and GitHub links.

## 🛠️ Technologies Used
- **HTML5** (Semantic structure)
- **CSS3** (Styling, Flexbox/Grid, Responsive Design, Dark Mode)
- **JavaScript** (Theme toggling, `localStorage`, and interactivity)
- **GitHub & GitHub Pages** (Version control and live hosting)
